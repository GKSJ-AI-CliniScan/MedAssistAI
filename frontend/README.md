# 🏥 MedAssist AI - Frontend

## 📌 Project Overview

MedAssist AI is an AI-powered healthcare web application developed to assist users in identifying possible diseases based on the symptoms they provide. The frontend is built using React and Vite, providing a modern, responsive, and user-friendly interface for patients.

This milestone focuses on the frontend development, routing, UI components, responsive design, and Docker containerization.

---

## 🚀 Features

- Responsive Landing Page
- User Login & Registration
- Patient Dashboard
- Symptom Checker
- AI Disease Prediction Interface
- Health Reports Module
- User Profile Management
- Interactive Analytics Dashboard
- Local Storage Integration
- Docker Support

## ⚙️ Installation

Clone the repository

```bash
git clone <repository-url>
```

Move to the frontend directory

```bash
cd frontend
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm run dev
```

The application will start at:

```
http://localhost:5173
```

---

## 🐳 Docker Support

Build and run using Docker Compose

```bash
docker compose up --build
```

The application will be available at:

```
http://localhost:5173
```
