## 🚀 How to Access the Application

1. Open the live website:
   https://med-assist-ai-d2yh.vercel.app/

2. Go to the login page.

3. Enter the username and password for the required role from the table above.

4. No OTP verification is required for demo accounts.

5. After successful login, the application will redirect you to the corresponding role dashboard.

6. Explore the features available for that role.
